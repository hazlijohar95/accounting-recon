# Demo Mode

Want to explore Reconciled before signing up? Demo mode lets you experience the full platform with sample data—no account required.

## Accessing Demo Mode

1. Go to [reconciled.app](https://reconciled.app)
2. Click **Try Demo** on the landing page
3. You're in! Explore with pre-loaded sample data

<Note>
  Demo mode uses sample data from a fictional company. No real financial data is involved, and nothing you do is saved.
</Note>

## Sample Data Overview

The demo includes data for **Acme Trading Co.**, a fictional import/export business:

| Data Type | Records | Date Range |
|-----------|---------|------------|
| Bank Transactions | 150+ | Jan - Dec 2024 |
| Invoices | 120+ | Jan - Dec 2024 |
| Receipts | 80+ | Jan - Dec 2024 |

The sample data includes:
- Various transaction amounts (small and large)
- Multiple vendors and customers
- Date discrepancies for window matching
- Partial description matches for fuzzy matching
- Complex scenarios for AI semantic matching

## What You Can Do

### Run Reconciliation

Click **Reconcile** to see the 5-layer matching in action:

1. Watch exact matches appear instantly
2. See window matching find date-offset transactions
3. Observe reference matching link invoice numbers
4. Experience fuzzy matching on partial descriptions
5. View AI semantic matching understand context

### Review Matches

Practice the review workflow:

- Use keyboard shortcuts (`A` to approve, `R` to reject)
- Navigate with arrow keys
- Filter by match status
- Search for specific transactions

### Explore Reports

Generate sample reports:

- Summary reconciliation report
- Detailed match listing
- Unmatched items report

### Try Workspaces

Create an AI-powered worksheet:

1. Add columns with different data types
2. Use `=ENRICH()` formulas for AI enrichment
3. Paste data from external sources

## Limitations

Demo mode has some restrictions:

| Feature | Demo Mode | Full Account |
|---------|-----------|--------------|
| Upload files | ❌ | ✅ |
| Save changes | ❌ | ✅ |
| Export reports | Preview only | Full export |
| Data persistence | None | Permanent |
| Multiple sessions | No | Yes |

<Warning>
  Nothing in demo mode is saved. When you close the browser or refresh, all changes are lost.
</Warning>

## Converting to Full Account

Ready to use Reconciled with your own data?

1. Click **Sign Up** in the top navigation
2. Create your account (see [Sign Up](/getting-started/signup))
3. Complete onboarding
4. Upload your actual files

Your demo session doesn't transfer—you'll start fresh with a clean workspace for your real data.
